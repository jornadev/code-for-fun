##  Funcionalidades

O projeto conta atualmente com as seguintes features:

- [x] **Trilhas Interativas:** Caminho de aprendizado gamificado com animações e mascote.
- [x] **Quizzes de Lógica:** Sistema de perguntas e respostas com feedback visual imediato.
- [x] **Gamificação:** Sistema de rankings (Leaderboard) e pontuação (XP) para engajamento.
- [x] **Dark Mode:** Suporte completo a tema escuro e claro.
- [x] **Autenticação:** Sistema de autenticação confiável e seguro com Firebase Authentication.

##  Como rodar o projeto

Siga os passos abaixo para rodar o aplicativo na sua máquina local.

### Pré-requisitos

Você precisa ter instalado:
1.  [Flutter SDK](https://docs.flutter.dev/get-started/install)
2.  Android Studio (recomendado).
3.  Um emulador ou um dispositivo físico conectado.

### Instalação

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/jornadev/code-for-fun.git

2. **Entre na pasta do projeto:**

   ```bash
    cd code-for-fun

3. **Instale as dependências:**

    ```bash
    flutter pub get
    
4. **Execute o aplicativo:**

    ````bash
    flutter run
